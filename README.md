# Gold Futures Market Analytics Dashboard

## Files
Upload these files to the root of your GitHub repository:
- app.py
- Gold Futures Historical Data.json
- requirements.txt
- README.md

## Streamlit deployment
1. Push the files to GitHub.
2. Open Streamlit Community Cloud.
3. Select your repository and branch.
4. Set Main file path to `app.py`.
5. Deploy.

The dashboard includes OHLC price action, volume, daily change, intraday range,
risk analytics (Historical VaR 95%/99%, maximum drawdown), short-term forecast,
executive insight, and downloadable filtered data.
